## 2026-06-30 - Accessible Progress Indicators in Minimalist Interfaces
**Learning:** Custom progress indicator dots in multi-step wizard flows often lack native accessibility, keyboard focus capability, and screen-reader context. Transitioning decorative lines to siblings of the list elements inside a semantic `<nav>` container maintains HTML validity, while a `group` and `group-focus-visible` token approach allows focus rings to beautifully surround only the custom visual indicators without disrupting minimalist design offsets.
**Action:** Always wrap custom stepper components in a semantic `<nav>` and `<ol>` block. Replace non-button list elements with accessible, style-stripped `<button type="button">` items, and apply `group-focus-visible` to target nested visual indicators.
