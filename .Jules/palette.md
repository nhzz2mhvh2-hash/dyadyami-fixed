## 2026-06-30 - Accessible Progress Indicators
**Learning:** Progress indicator components like wizard progress dots must use semantic HTML (`<nav>`, `<ol>`, `<li>`, and `<button type="button">` with `aria-current="step"`) to remain fully accessible to screen readers and keyboard navigation. Decorative lines connecting the steps must be placed as absolute-positioned siblings to the list rather than within the list hierarchy to maintain clean semantic structure, and buttons must use focus-visible states with high offsets like `focus-visible:ring-offset-4` to provide visual affordance on custom-styled interactive dots.
**Action:** Always wrap progress dot indicators in a `<nav>` with a nested `<ol>` list of steps, use native buttons with custom styling for each step instead of raw click-handling `div` containers, and style focus states explicitly using high-offset luxury rings.
