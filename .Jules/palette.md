# Palette's Journal - Dyadyami

## 2025-05-14 - Global Accessibility Barriers
**Learning:** The "quiet luxury" design philosophy in this app led to the removal of standard accessibility features like the system cursor and focus indicators, which severely hinders navigation for many users.
**Action:** Always verify that 'quiet luxury' aesthetic choices do not override core accessibility needs (WCAG). Restore cursors and focus rings as a baseline.
