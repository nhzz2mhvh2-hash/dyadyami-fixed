## 2026-06-30 - Refactoring Wizard Progress Indicators for Screen Readers and Keyboard Accessibility
**Learning:** Progress indicators styled as pure decorative layouts prevent screen reader users and keyboard-only users from understanding the structure and status of a multi-step booking process. Utilizing a semantic `<nav>` with nested `<ol>`, `<li>`, and `<button>` elements with clear `aria-current="step"` and custom `aria-label`s makes the progression instantly comprehensible and navigable.
**Action:** Always wrap wizard and multi-step progress indicators in semantic navigation tags, map individual progress points to interactive elements with explicit ARIA labels specifying status (e.g. Completed, Current, Step X of Y), and implement visual-focus rings wrapping only the interactive target inside nested list tags.
