## 2026-06-30 - Accessible Progress Indicators in Multi-step Flows
**Learning:** Progress indicators that allow backtracking or step selection must use semantic HTML (`<nav>` and `<ol>`) and `<button type="button">` with descriptive `aria-label` and `aria-current="step"`. When a parent button wraps a visual element like a nested progress dot, using the tailwind `group` class on the parent and `group-focus-visible` on the child ensures that focus rings elegantly target the visual element while retaining full accessibility.
**Action:** Always wrap interactive step indicator tracks in `<nav aria-label="Progress">` and `<ol>`, use standard `<button>` elements instead of clickable divs, and apply the `group` class structure to handle keyboard focus indicators on custom nested UI elements cleanly.
