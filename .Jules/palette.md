## 2026-06-30 - Accessible Progress Indicators in Immersive Web Wizard Designs
**Learning:** In a quiet luxury aesthetic with deep ambient colors and sparse neon active states (like cyan-luxury), visual-only progress indicators (using simple styled divs) ignore essential assistive technology semantics. Converting them to `<nav>`, `<ol>`, and `<button type="button">` elements with explicit accessibility attributes provides screen readers with context of the multi-step form structure, active step state via `aria-current="step"`, and interactive availability without altering the minimalist layout design.
**Action:** When creating custom progress indicators, always leverage semantic wrapping and explicit custom button components, and utilize high contrast, high-offset focus indicators paired with tailwind focus utility groups (e.g., `group-focus-visible:ring-offset-black`) to ensure keyboard navigability matches visual cues.
