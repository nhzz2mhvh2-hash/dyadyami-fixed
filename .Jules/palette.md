## 2026-06-30 - Semantic Progress Indicators in Minimalist UI
**Learning:** In "quiet luxury" or minimalist designs, decorative elements (like progress lines) often override semantic structures. Using a `<nav>` with an `<ol>` and `<button>` elements ensures that the UI remains accessible to screen readers and keyboard users without compromising the "void" aesthetic.
**Action:** Always wrap progress indicators in `<nav>` containers and use `<button type="button">` for interactive dots to maintain semantic validity and focus affordance.
